## 🛠️ Troubleshooting Tips

### Connection Issues
- Verify both devices are on the same network
- Check that your PC's firewall allows incoming connections on the telemetry port
- Confirm the telemetry port number matches in both the game settings and rigdeck

### GPS Not Working
- Ensure "Developer Mode" is enabled in game options
- Try restarting the game after changing telemetry settings
- Verify your game files are up to date

### vJoy Controls Not Responding
- Reinstall the vJoy driver software
- Restart your PC after installing vJoy
- Check device manager to confirm vJoy is recognized
